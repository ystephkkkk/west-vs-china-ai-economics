# Tokens vs Dollars: West vs China on OpenRouter

**Dashboard:** https://ystephkkkk.github.io/west-vs-china-ai-economics/

Weekly token volume and estimated economic value on OpenRouter, split between Western and Chinese
model vendors, with the within-vendor tier mix for Anthropic, OpenAI and Google, an external
capability cross-check (Artificial Analysis, METR) and third-party GPU rental and token price indexes.

Data through the week ending 2026-10-04 (weeks run Monday to Sunday and are labelled by their ending date). That week is provisional: its totals were still being revised when the dashboard was built.

- **Sources:** [OpenRouter rankings](https://openrouter.ai/rankings) and
  [model catalog](https://openrouter.ai/models) (token volume, list prices);
  [Artificial Analysis](https://artificialanalysis.ai/) (Intelligence Index capability, cost and
  time per task -- credited from manual, dated snapshots for non-commercial research use, not a
  live feed); [METR time horizons](https://metr.org/time-horizons/) (task length);
  [Silicon Data](https://www.silicondata.com/), [SemiAnalysis](https://gpu-index.semianalysis.com/)
  and [Ornn AI](https://data.ornn.com/) (daily GPU rental and LLM token price indexes -- a manual,
  dated pull, not a live feed).
- **Scope:** OpenRouter is a small, developer- and agent-skewed slice of global token demand. Read
  shares as a venue-level signal, not global market share.
- **Dollar figures** are estimates (token volume x per-vendor rates built from catalog list prices and
  fixed per-vendor reference prices), not reported revenue; read them as bands.

Not investment advice.
